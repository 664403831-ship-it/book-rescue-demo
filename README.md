# 增长产品交互原型作品集

本仓库收录两个个人模拟增长产品项目，均可通过 GitHub Pages 直接体验。

## 项目一：小说 App「书荒急救站」

小说 App 增长产品模拟项目，围绕用户“书荒”和找书效率问题，设计从阅读需求表达、自然语言找书、推荐选择到三章试读的完整体验。

## 核心功能

- 阅读场景、题材和口味选择
- 自然语言找书及条件识别
- 三本高匹配小说推荐
- 推荐理由与匹配度展示
- 三章试读及阅读进度
- 试读中直接切换书籍
- 返回推荐列表重新选择
- 试读后的收藏、换书及负反馈

## 项目二：携程「一起选」多人旅行共同决策

旅游 App 增长与交易产品模拟项目，围绕多人旅行选酒店时决策分散、意见难统一的问题，连接候选酒店选择、邀请分享、共同投票、进度提醒、结果生成和预订承接。

### 核心功能

- 选择 2—3 家候选酒店
- 创建共同选择并设置人数、截止时间
- 微信好友、群聊和链接邀请
- “最想住 / 不能接受”双向投票
- 投票进度与未完成成员提醒
- 基于共识生成推荐结果
- 结果页承接酒店预订转化

### 增长指标

- 分享率：衡量站外传播效率
- 投票完成率：衡量多人协作效率
- 预订转化率：衡量交易增长结果

## 使用方式

项目均为静态交互原型，通过页面顶部导航切换体验。
